# PGS Hub Role Matrix

Legend: `View`, `Create`, `Update`, `Manage/Approve`.

| Module                       | Admin                       | Accountant                               | Team Leader                                         | Employee                                      | Client                                               |
| ---------------------------- | --------------------------- | ---------------------------------------- | --------------------------------------------------- | --------------------------------------------- | ---------------------------------------------------- |
| Auth/account status          | Manage/Approve              | Own account                              | Own account                                         | Own account                                   | Own account                                          |
| Departments/teams            | Manage                      | View limited                             | View assigned/team scope                            | View limited                                  | No internal access                                   |
| Employee profiles            | Manage                      | View finance-needed data                 | View team/project-needed data                       | Own profile                                   | No internal access                                   |
| Client companies/memberships | Manage                      | View finance-needed client records       | View project-needed client records                  | View project-needed client records            | Own linked companies                                 |
| Projects                     | Manage                      | View finance-needed projects             | View/update authorized projects                     | View assigned/member projects                 | View linked client projects                          |
| Project members              | Manage                      | View finance-needed memberships          | Manage authorized project memberships where allowed | View own project membership                   | View own client project access                       |
| Services/project services    | Manage                      | View finance-needed service data         | View project services                               | View project services                         | View client-visible project services                 |
| Tasks/Kanban/calendar        | Manage                      | View finance-needed task/project context | Create/update assigned project tasks                | Create/update own assigned/member tasks       | View client-visible project tasks                    |
| Comments/files               | Manage                      | View finance-needed files/comments       | Create/view authorized project comments/files       | Create/view authorized project comments/files | Create/view authorized client-visible comments/files |
| Attendance                   | Manage/review               | No default access                        | View/review team scope where implemented            | Create/view own records                       | No access                                            |
| Leave                        | Manage/approve              | No default access                        | View/review team scope where implemented            | Create/view own requests                      | No access                                            |
| Contracts                    | Manage                      | Manage                                   | View if project-authorized and needed               | No default finance access                     | View client-visible contracts                        |
| Invoices/payments            | Manage                      | Manage                                   | View if project-authorized and needed               | No default finance access                     | View client-visible invoices                         |
| Notifications                | Manage own/system-generated | Own notifications                        | Own notifications                                   | Own notifications                             | Own notifications                                    |
| Chat                         | Manage/admin scope          | Finance-authorized chats                 | Authorized project/direct chats                     | Authorized project/direct chats               | Authorized client project chats                      |
| Automation                   | Manage                      | No access                                | No access                                           | No access                                     | No access                                            |

Controllers and services remain the source of truth for the exact permission checks. This matrix documents the intended release posture and should be updated with every RBAC-affecting change.
