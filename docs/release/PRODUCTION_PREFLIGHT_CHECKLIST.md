# Production preflight checklist

Complete this **before** any production deployment is proposed. A row is only `DONE` when its evidence column points to something that was actually run or read. Missing access is `BLOCKED`, never `DONE`. Environment vocabulary: `LOCAL / CI` (disposable, in a runner), `STAGING` (separate project, does not exist yet), `PRODUCTION`.

Status as of 2026-10-20 (author had no production, staging, Vercel, cPanel or Supabase-dashboard access).
